# Emmet Speedrun Game 🎮

Un juego interactivo desarrollado para masterizar el uso de **Emmet**, el motor de abreviaciones que permite escribir código HTML y CSS a una velocidad increíble. Este proyecto fue una pieza clave en mi formación técnica para explorar la interactividad web y la lógica de programación.

---

### 🎯 ¿Qué es Emmet?
Emmet es un motor de abreviaciones integrado por defecto en los editores de código modernos (como VS Code). Permite transformar abreviaturas cortas en bloques completos de código mediante la tecla `Tab`.

**Ejemplo:** `div.container>ul.nav>li.item*5` se expande a una estructura completa de lista navegable en segundos.

---

### 🕹️ Cómo jugar
1. **Descarga o clona** este repositorio en tu PC.
2. Localiza el archivo principal **`HyperTech Style.html`**.
3. Ábrelo en tu navegador preferido.
4. Resuelve los desafíos de sintaxis Emmet para avanzar de nivel y mejorar tu velocidad de desarrollo.

---

### 🛠️ Tecnologías y Herramientas
Este proyecto destaca por la integración de múltiples áreas técnicas y creativas:

* **Lógica de Juego:** JavaScript (implementado para el control de eventos y niveles).
* **Animación y Diseño:** Adobe Animate (.fla).
* **Multimedia:** Edición de video profesional con Adobe Premiere.
* **Estructura:** HTML5 Canvas y CSS3.

### 📂 Estructura del Proyecto
El repositorio incluye los archivos fuente originales para su inspección técnica:
* `HyperTech Style.fla`: Archivo fuente de Adobe Animate.
* `HyperTech Style.js`: Lógica exportada del juego.
